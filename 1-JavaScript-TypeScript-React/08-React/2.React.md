# react

## 1. JSX

JSX, JavaScript içinde HTML benzeri bir sözdizimidir.

### Örnek:

```jsx
const element = <h1 className="title">Merhaba, Dünya!</h1>;
```

### Dikkat:

- `class` yerine `className`
- `for` yerine `htmlFor`
- Tek bir parent element gerekir: Fragment (`<> </>`) veya `div`

---

## 2. Component (Bileşen)

React’te her şey bileşendir. Fonksiyonel veya class bileşen olabilir.

### Fonksiyonel Component:

```jsx
function Selamla() {
  return <h2>Merhaba!</h2>;
}
```

### Props ile:

```jsx
function Selamla(props) {
  return <h2>Merhaba, {props.isim}!</h2>;
}

// Kullanımı:
<Selamla isim="Ayşe" />
```

---

## 3. Props (Özellikler)

Bir component'e dışarıdan veri iletmek için kullanılır.

- Read-only’dır.
- Obje şeklinde component'e iletilir.

```jsx
function Profil({ isim, yas }) {
  return <p>{isim}, {yas} yaşında</p>;
}

<Profil isim="Ali" yas={25} />
```

---

## 4. State (Durum)

Component’in kendi iç durumu. Değiştiğinde component yeniden render olur.

```jsx
import { useState } from 'react';

function Sayaç() {
  const [sayi, setSayi] = useState(0);

  return (
    <><p>Sayı: {sayi}</p>
      <button onClick={() => setSayi(sayi + 1)}>Arttır</button>
    </>
  );
}
```

---

## 5. useEffect (Yan Etkiler)

Component yüklendiğinde, güncellendiğinde veya yok edildiğinde çalışan kodları yazmak için.

```jsx
import { useEffect } from 'react';

useEffect(() => {
  console.log("Component yüklendi!");

  return () => {
    console.log("Component kaldırıldı!");
  };
}, []);
```

- İkinci parametre (dependency array) yoksa: her render'da çalışır.
- Boş array: sadece ilk yüklemede çalışır.
- Değişken verilirse: o değişken değiştiğinde çalışır.

## 6. Event Handling (Olay Yakalama)

React’te olaylar camelCase ile yazılır.

```jsx
function Buton() {
  const tikla = () => alert("Tıklandı!");
  return <button onClick={tikla}>Tıkla</button>;
}
```

## 7. Conditional Rendering (Koşullu Gösterim)

```jsx
function Kullanici({ girisYapildi }) {
  return girisYapildi ? <p>Hoş geldin!</p> : <p>Lütfen giriş yap.</p>;

```

Alternatif olarak:

```jsx
{isLoading && <p>Yükleniyor...</p>}
```

## 9. Forms (Formlar)

Controlled Component yapısı ile input verilerini state ile yönetiriz.

```jsx
function Form() {
  const [isim, setIsim] = useState("");

  const handleChange = (e) => setIsim(e.target.value);

  return (
    <input type="text" value={isim} onChange={handleChange} />
  );
}
```

## 10. Lifting State Up

State birden fazla component tarafından kullanılacaksa, ortak parent’a taşınır.

```jsx
function Parent() {
  const [data, setData] = useState("");

  return (
    <><Input setData={setData} />
      <Goster data={data} />
    </>
  );
}
```

## 11. Context API

Global state gibi düşünülebilir. Redux’sız veri paylaşımı.

```jsx
const TemaContext = createContext("light");

function App() {
  return (
    <TemaContext.Provider value="dark">
      <TemaButon />
    </TemaContext.Provider>
  );
}

function TemaButon() {
  const tema = useContext(TemaContext);
  return <button>{tema} tema</button>;
}
```

## 12. Custom Hooks

Kendi `use` ile başlayan fonksiyonel mantıklarını yazarsın.

```jsx
function useSayac(baslangic = 0) {
  const [sayi, setSayi] = useState(baslangic);
  const arttir = () => setSayi(sayi + 1);
  return [sayi, arttir];
}
```

## REDUX (State Yönetimi)

---

## 1. Redux Nedir?

Uygulama seviyesinde **global state** yönetim aracıdır. Tüm componentler ortak bir veri kaynağını kullanır.

---

## 2. Temel Kavramlar

- **Store**: Tüm state'in tutulduğu yer
- **Action**: Ne yapılacağını söyleyen JavaScript objesi `{ type: 'ARTTIR' }`
- **Reducer**: State’in nasıl değişeceğini belirleyen saf fonksiyon
- **Dispatch**: Action’ı reducer’a gönderme işlemi

---

## 3. Basit Redux Örneği

### Action:

```jsx
const arttir = () => ({ type: 'ARTTIR' });
```

### Reducer:

```jsx
function sayacReducer(state = 0, action) {
  switch (action.type) {
    case 'ARTTIR':
      return state + 1;
    default:
      return state;
  }
}
```

### Store Oluşturma:

```jsx
import { createStore } from 'redux';
const store = createStore(sayacReducer);
```

### Kullanma:

```jsx
store.dispatch({ type: 'ARTTIR' });
console.log(store.getState()); // 1
```

---

## 4. React-Redux ile Kullanım

```bash
npm install redux react-redux
```

### Provider:

```jsx
import { Provider } from 'react-redux';

<Provider store={store}>
  <App />
</Provider>
```

### `useSelector` ve `useDispatch`:

```jsx
import { useSelector, useDispatch } from 'react-redux';

function Sayac() {
  const sayi = useSelector((state) => state);
  const dispatch = useDispatch();

  return (
    <><p>{sayi}</p>
      <button onClick={() => dispatch({ type: 'ARTTIR' })}>+</button>
    </>
  );
}
```

## 5. Redux Toolkit (Modern Redux)

Redux işlemlerini basitleştiren modern araç.

```bash
npm install @reduxjs/toolkit
```

### Slice Oluşturma:

```jsx
import { createSlice } from '@reduxjs/toolkit';

const sayacSlice = createSlice({
  name: 'sayac',
  initialState: 0,
  reducers: {
    arttir: (state) => state + 1,
  },
});

export const { arttir } = sayacSlice.actions;
export default sayacSlice.reducer;
```

### Store:

```jsx
import { configureStore } from '@reduxjs/toolkit';
import sayacReducer from './sayacSlice';

const store = configureStore({
  reducer: sayacReducer,
});
```
